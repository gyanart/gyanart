# GyanArt SEO Phase 1 — prioritized implementation and validation backlog

**Updated:** 18 October 2026 · **Owner:** GyanArt · **Tracker:** [Issue #39](https://github.com/gyanart/gyanart/issues/39)

## Business objective and scope

Win qualified **website design enquiries from small businesses in Bangalore/Bengaluru**. The homepage (`/`, `/hi/`, `/kn/`) now targets the commercial website-designer cluster; `/website-design.html` and its translations explain service details, scope and process. Local SEO and Google Business Profile optimization remain complementary services. Do not create another landing page with identical search intent. LogoEx and UXGyan work is excluded.

**Source evidence:** GSC 11–17 Oct 2026: 11 clicks, 67 impressions, 16.42% CTR (property chart). `website designer bangalore`: 4 query impressions, 0 clicks, mean position 4.25; URL attribution involved homepage/solutions variants, not the Website Design page. Query/page export totals do not reconcile with chart totals. GA4 Organic Search: 39 sessions, 12 key events (NOT 12 unique leads). Page indexing export dated 18 Oct shows latest populated snapshot on 12 Oct: 17 indexed and 25 not indexed. These are **small, lagged observations**, not current crawler state.

**Implementation already shipped:** PR #40 improved Website Design above-fold rendering and heading hierarchy; #41 added footer spacing; #42 switched EN/HI/KN homepage positioning; #43 localized service CTAs and OG locale fallback. All were merged and GitHub Actions FTP deployment steps reported success. **Those successful CI/FTP uploads do not prove live HTTP behavior, visual parity or ranking gains.**

## Execution and evidence gates

1. **Never mark a source rule as an independently confirmed live HTTP result.** The available model web retrieval returned the GyanArt public URLs as inaccessible; this does *not* establish website downtime. GSC URL Inspection and a direct browser/HTTP check will be needed for SEO-01–03.
2. **Implement narrowly** on a dedicated branch and PR; run production build and page-specific tests; merge/deploy when requested under the user's approved GyanArt workflow; verify the exact final `main` commit against the **successful final FTP deployment run**.
3. **Do not request repeated GSC indexing** unless the eligible canonical URL genuinely changed or inspection shows a need.
4. **Do not guarantee rankings, search volume, Core Web Vitals field scores or unique leads** from Lighthouse, tiny GSC query samples, or GA4 key-event counts.
5. Order of work: SEO-01 and SEO-02 evidence collection first; SEO-03 language verification; SEO-04 and SEO-05 post-deployment measurement; SEO-06 automation; SEO-07/08 only after higher-priority blockers are addressed.
6. Phase 1 can be marked **baseline + documented backlog complete** even when time/access-dependent live checks and post-change performance outcomes remain open in Issue #39; these become Phase 2 execution/monitoring tasks.
