# Article drafts and reviews

Place one Markdown file per article in this directory. Include the metadata fields shown in `../templates/article-brief.md` plus `title`, `slug`, `status`, `primary_keyword`, `meta_description`, `description`, and `updated`. Use `draft` until the factual, SEO and editorial checks are complete. Setting `approved` does not publish an article. This folder is not copied into the website build.
