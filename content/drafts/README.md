# Draft articles

Keep research notes and unpublished article drafts here. The static site builder does not read this folder, so draft material is not published to the website.

Use the article brief and prompts in `content/templates/`. Store one article per Markdown file and include the required metadata at the top. Move content to the website source only after explicit human approval; changing a draft status alone does not publish it.

Suggested filename: `YYYY-MM-DD-short-topic-slug.md`.
