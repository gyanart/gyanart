# GyanArt pre-publication checklist

## Audience and usefulness
- [ ] Serves a specific business owner/customer need.
- [ ] Answers the main question near the start.
- [ ] Offers useful original judgement, a practical process, checklist or example.
- [ ] Does not exist only to target a keyword or repeat another article.

## Research and accuracy
- [ ] Every material factual claim checked against an opened source.
- [ ] Prefer primary/official sources for platform features and policies.
- [ ] Statistics, dates, prices and named entities are current and correctly represented.
- [ ] No fabricated sources, search volumes, quotes, client results or personal experiences.
- [ ] Limitations and uncertainty are made clear.
- [ ] Permissions and attribution are handled for images, quotations and third-party assets.

## On-page SEO
- [ ] One clear H1 and logical H2/H3 structure.
- [ ] Descriptive title tag (usually around 50–60 characters as a guideline, not a hard ranking rule).
- [ ] Unique meta description (usually around 140–160 characters as a guideline, not a hard ranking rule).
- [ ] Readable lowercase slug with hyphens.
- [ ] Primary phrase used naturally in title/intro where appropriate.
- [ ] No keyword stuffing or repetitive headings.
- [ ] Image alt text describes meaningful image content; decorative images are treated appropriately.
- [ ] Canonical URL is correct and page is indexable for production.
- [ ] Article is included in Insights and the XML sitemap at publication.

## Links and conversion
- [ ] Internal links point to real, relevant GyanArt pages.
- [ ] Descriptive anchor text explains the destination.
- [ ] External citations support the claims they accompany and open correctly.
- [ ] No broken links, placeholder URLs or misleading CTA.
- [ ] CTA is relevant and low pressure (for example, request a Growth Audit).

## UX and technical QA
- [ ] Short paragraphs, lists and tables used where helpful.
- [ ] Mobile layout, headings, images and links reviewed.
- [ ] Keyboard focus and link text remain usable.
- [ ] No accidental personal/customer information disclosed.
- [ ] Generated static HTML has correct title, description, canonical, robots and structured data as appropriate.
- [ ] Build succeeds and all links/assets resolve.

## Human approval
- [ ] Status changed to `review` only when checks above are complete.
- [ ] Gyaneshwar reviewed the final article and sources.
- [ ] Explicit approval is recorded in the pull request before publication changes are merged.
- [ ] Production remains untouched unless a separate go-live decision is made.
