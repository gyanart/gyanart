# GyanArt local SEO + GEO content

1. First review `AGENTS.md`, the approved keyword-to-page map and current GyanArt positioning. Don't guess prices, service areas, client outcomes or credentials.
2. Match each page with one dominant buyer intent. Homepage leads with local website design; service pages clarify process and scope. Don't create overlapping city or industry doorway pages.
3. Check page title, localized H1, useful first paragraph, actual services/limits, accessible next action, simple enquiry path, internal linking, informative alt text and accurate metadata.
4. Prefer concise factual explanations and demonstrable examples. For any case study, distinguish real delivered work from demo/proposal and verify permission for testimonials and names.
5. Check EN/HI/KN variants are genuinely equivalent, with expected self-canonicals, reciprocal hreflang and correct local-language navigation.
6. Check actual public business name, primary category, contact details and location policy before recommending GBP or LocalBusiness/Organization schema edits. Schema must match visible page content.
7. Check with Google Rich Results Test or Schema.org Validator if possible; don't add FAQ/HowTo markup to chase unsupported/retired Google rich results.
8. Write recommendations as “existing URL -> visitor problem -> specific improvement -> source/proof -> measurable next step.” Do not claim rankings or AI citations until observed.

No paid SEO tools or APIs needed. No auto-publication.
